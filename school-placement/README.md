# Приложение оценки вариантов размещения школ (Омск, Практика 3)

Интерактивное Streamlit-приложение для оценки ручных и автоматически подобранных вариантов размещения **одной** новой школы относительно baseline-обеспеченности местами в школах.

## Запуск (Windows, PowerShell)

Из корня проекта `C:\Users\xoxom\Desktop\ТИИ`:

```powershell
cd C:\Users\xoxom\Desktop\ТИИ
.\.venv\Scripts\Activate.ps1
pip install -r school-placement\requirements.txt
streamlit run school-placement\app.py
```

Приложение читает исходные данные проекта только на чтение и сохраняет экспортируемые сценарии/результаты в `school-placement\exports\`.

## Источники данных (read-only)

- `data\omsk_blocks.geojson` — 5643 квартала, `block_id = 0..5642` (порядок features).
- `data\omsk_population.geojson` — `block_id`, `population`, `school_age_population`.
- `data\omsk_schools_capacity.geojson` — `block_id`, `schools_count`, `capacity` (baseline).
- `output\omsk_accessibility_drive_minutes.csv` — матрица доступности (drive), минуты, 5643×5643, индексы `0..5642`.
- `output\omsk_provision_baseline.geojson` — baseline-обеспеченность.
- `NOTES.md` — метод и параметры baseline.

## Метод и параметры расчёта

- Движок: `blocksnet.analysis.provision.competitive_provision` (BlocksNet 1.0.0a9).
- Спрос: `demand = ceil(population * 120 / 1000)` (`DEMAND_PER_1000 = 120`), строго как в baseline. `school_age_population` используется только для отображения.
- Порог доступности: `ACCESSIBILITY_MIN = 20` минут (из `NOTES.md`), `self_supply=True`, `max_depth=1`.
- Базовая вместимость существующих школ: восстановлена нормативно (550 мест/школа в исходном агрегате) — **оценка, не данные OSM**.
- Вместимость новой добавляемой школы по умолчанию: `DEFAULT_NEW_SCHOOL_CAPACITY = 600` мест.
- Матрица читается с `dtype=float32` один раз.

## Направление матрицы доступности

- Принятая интерпретация: `acc[i, j]` — время в минутах от квартала `i` (население/спрос) к кварталу `j` (объект/школа), т.е. направление **i → j**. Маска достижимости: `acc[i, j] <= ACCESSIBILITY_MIN`.
- Интерпретация согласована с построением матрицы в ноутбуке (строка — исходный квартал, столбец — целевой) и с логикой `competitive_provision`.
- При старте приложение выполняет проверку направления на тестовом квартале и выводит результат в интерфейсе (и использует зафиксированное направление `i → j` для прокси).

## Автоподбор одной школы: прокси + топ-K (ограничение)

Полный точный перебор 5643 кварталов с `competitive_provision` для каждого невозможен по приемлемому времени.

Используемая схема:
1. **Прокси (все 5643, векторно):** для каждого кандидата `j` оценивается покрытие неудовлетворённого спроса baseline в зоне доступности `proxy_gain_j = min(C_new, Σ_i demand_left_i · [acc[i,j] <= A])`.
2. **Точная проверка топ-K:** для `K` лучших по прокси (по умолчанию `K=50`, настраивается) выполняется точный `competitive_provision` и считаются метрики/сокращение дефицита.
3. В таблице отображаются **все 5643** квартала с пометкой режима `точно`/`прокси`; при равенстве лучшего точного результата показываются все равные.
4. **Долгий режим (опция):** полный точный перебор всех 5643 с прогрессом и сохранением промежуточных/итоговых результатов в `school-placement\exports\` (после каждого шага освобождается память).

## Допущения и ограничения

- Население и спрос — модельные/нормативные оценки; вместимость существующих школ восстановлена нормативно (не фактическая).
- Результаты оценки чувствительны к параметрам (`ACCESSIBILITY_MIN`, `DEMAND_PER_1000`, `C_new`) и к качеству исходных данных.
- Прокси — верхняя эвристическая оценка потенциального покрытия; окончательное сравнение кандидатов в быстром режиме делается по точному расчёту топ-K.
- После каждого `competitive_provision` выполняется освобождение памяти (`del` + `gc.collect()`); в батчах результаты сохраняются на диск.

## Проверки

См. `tests_check.py`:

```powershell
.\.venv\Scripts\Activate.ps1
python school-placement\tests_check.py --integrity --baseline
python school-placement\tests_check.py --autopick-smoke --k 3
```

Контрольные условия: без новых школ результат воспроизводит baseline (max |Δprovision_strong| < 1e-6); ручное размещение в найденном квартале даёт результат автоподбора; при равенстве лучших показываются все.
